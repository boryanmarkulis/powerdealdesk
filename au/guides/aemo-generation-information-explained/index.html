What is the AEMO Generation Information page and how to read it

AEMO Generation Information is a regularly updated AEMO publication listing existing, committed and proposed generation and storage in the NEM, based on surveys of project proponents. Its spreadsheet gives each unit's region, technology, nameplate capacity, storage size and commitment status (e.g. Publicly Announced, Anticipated, Committed), making it the standard public pipeline register.

How to read it

  • Download the latest spreadsheet from the AEMO page (one file per NEM-wide release).
  • The main generator sheet has one row per unit; hybrid sites have separate solar and battery rows.
  • Filter by technology (e.g. Battery Storage) and region (NSW1, QLD1, VIC1, SA1, TAS1).
  • Commitment status shows maturity. AEMO publishes the commitment criteria (site, components, planning, finance, construction) on the same page.
  • Check the survey-update date: stale entries can indicate stalled projects.

Limitations

Data is proponent-reported and can lag reality. We found several entries whose MW differ from planning records; see the tracker notes.

FAQ

How often is AEMO Generation Information updated?

AEMO publishes updates several times a year; check the page for the latest release date.

What does "Anticipated" mean?

A project that meets some but not all of AEMO's commitment criteria and is progressing toward commitment, per AEMO's published definitions.

Is the data verified?

It is based on information supplied by proponents; cross-check with planning and connection records.
