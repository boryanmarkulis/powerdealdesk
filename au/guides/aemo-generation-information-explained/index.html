What is the AEMO Generation Information page and how to read it

AEMO Generation Information is a regularly updated AEMO publication listing existing, committed and proposed generation and storage in the NEM, based on information AEMO collects from generation industry participants. Its spreadsheet gives each unit's region, technology, nameplate capacity, storage size and commitment status (e.g. Publicly Announced, Anticipated, Committed), making it the standard public pipeline register.

How to read it

  • Download the latest spreadsheet from the AEMO page (one file per NEM-wide release).
  • The main generator sheet has one row per unit; hybrid sites have separate solar and battery rows.
  • Filter by technology (e.g. Battery Storage) and region (NSW1, QLD1, VIC1, SA1, TAS1).
  • Commitment status shows maturity. The workbook's Background Information sheet sets out AEMO's five commitment criteria (land, contracts, planning, finance, construction).
  • Check the survey-update date: stale entries can indicate stalled projects.

Limitations

Data is proponent-reported and can lag reality. For example, AEMO lists Grahamvale BESS at 100 MW, while the developer's project page describes a 480 MW / 1,920 MWh proposal (source).

FAQ

How often is AEMO Generation Information updated?

AEMO says it publishes updates every three months, or as required; check the page for the latest release date.

What does "Anticipated" mean?

A project that is sufficiently progressed towards meeting at least three of AEMO's five commitment criteria, per the definitions in the workbook's Background Information sheet.

Is the data verified?

It is based on information reported by generation industry participants; cross-check with planning and connection records.
